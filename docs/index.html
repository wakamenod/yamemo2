YAMemo サポート

カテゴリごとに書き溜める、シンプルなメモ帳アプリ

使い方

カテゴリを作る
画面上部のタブの右端にある「＋」をタップし、名前を入力して「追加」を押します。
カテゴリの名前・並び順を変える／削除する
タブを長押しすると編集画面が開きます。名前の変更、スライダーでのタブ位置の変更、削除ができます。カテゴリを削除すると、その中のメモもすべて削除されます。
メモを書く
右下の「＋」ボタンをタップして本文を入力します。入力内容は自動で保存されます。右上のチェックボタンでも保存できます。
メモのカテゴリを変える
メモを開き、画面上部に表示されているカテゴリ名をタップして、移動先のカテゴリを選びます。
メモを削除する
一覧でメモを右から左へスワイプし、確認ダイアログで「削除」を選びます。
メニューを開く
一覧画面の左上のメニューから、バックアップとライセンス表示にアクセスできます。アプリのバージョンもここに表示されます。

バックアップと復元

メニュー →「バックアップ」から操作します。

バックアップを作成する
「バックアップを作成」を押すと JSON ファイル（yamemo_backup_日時.json）が作られ、共有メニューが開きます。「ファイル」アプリや Google ドライブ、メールの下書きなど、あとから取り出せる場所に保存してください。
バックアップから復元する
「バックアップから復元」を押し、保存しておいた JSON ファイルを選びます。

ご注意：復元すると、そのときアプリに入っているメモとカテゴリはすべて上書きされます。復元前に、念のため現在のデータのバックアップを取っておくことをおすすめします。

よくある質問

メモはどこに保存されますか？
お使いの端末の中だけに保存されます。メモの内容がサーバーに送信されることはなく、クラウド同期やアカウント登録の機能もありません。
機種変更するときはどうすればいいですか？
古い端末でバックアップを作成し、そのファイルを新しい端末に移してから復元してください。複数の端末で同じメモを自動的に同期することはできません。
アプリを削除するとメモはどうなりますか？
端末内のデータごと消えます。復元する手段はありませんので、アプリを削除する前に必ずバックアップを作成してください。
広告について教えてください。
一覧画面の下部にバナー広告を表示しています。広告を非表示にする有料プランは現在ご用意していません。
対応している言語は？
日本語と英語です。端末の言語設定に合わせて自動的に切り替わります。
使用しているオープンソースソフトウェアのライセンスは？
メニュー →「ライセンス」からご確認いただけます。
